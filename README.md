# 안녕하세요, 찐망고입니다.

### 웹 기술의 변화를 배우고, 가르치고, 직접 만들어갑니다.

2006년 플래시 기반 웹디자인 교육을 시작으로 웹표준, UI/UX, 그리고 현재의 AI 협업 개발까지. 변화하는 웹 기술을 익히고 교육 현장에 적용해 온 **UI/UX·웹 개발 강사**입니다.

교육 자료와 실습 프로젝트를 직접 기획·제작하며, 최근에는 AI를 활용해 웹서비스와 업무 자동화 도구를 만들고 운영하고 있습니다.

> **가르치는 기술을 직접 사용하고, 만드는 경험을 다시 교육으로 연결합니다.**
